# Open Bot — завершённый объём 1.0

- [x] Core / Web / Help / Info, правила, Components V2, конструктор и сообщения бота.
- [x] OAuth, текущие роли, CSRF, версии и сохранённые ID публикаций.
- [x] Подробный activity/error журнал, Redis batching и локальный outbox.
- [x] Ticket: панели/категории, приватные каналы, отдельные служебные ветки, разграничение ролей, история правок/удалений/вложений, закрытие и удаление архива через 180 дней.
- [x] Metrics: отдельный bearer endpoint, агрегация workers и тикетов, пример scrape и dashboard Grafana.
- [x] Game Server Status: SS14 status, кеш, наблюдения, web и slash-команды.
- [x] SS14 Watchdog: конфигурация, версии, restart/update/stop/revert, подтверждения и перезапуск сети.
- [x] Отдельная вики MkDocs Material с пользовательским и разработческим разделами; workflows приложения и документации.
- [x] Docker/Compose, backup, инструкции и проектные навыки.

Фактические результаты и ограничения среды — в [отчёте](docs/RELEASE-1.0.md). Тексты сообщества остаются пользовательскими данными. Публикация и power actions требуют явного действия администратора.
