# Open Bot 1.3

**Версия пакета: 1.3.0 · Git tag: v1.3.0 · 31 октября 2026 года.**

Релиз объединяет реализованные модули сообщества, мониторинг пяти игр, расширенную телеметрию и документацию. `tasks.md` содержит 113 выполненных функциональных пунктов и не содержит открытых задач. Сверены каталог, команды, серверные обработчики, настройки и сохраняемое состояние; внешние интеграции имеют описанные ниже ограничения.

## Исправления при подготовке выпуска

- Native AutoMod больше не исключает несинхронизированное правило из обработки ботом. Делегирование связано с точной конфигурацией; потеря ответа создания сверяется со списком Discord, удалённое правило восстанавливается, чужие правила не меняются. Валидация учитывает ограничения Native и различает целое слово/подстроку.
- Периодическая сверка Native и ручная синхронизация используют общий scope, исключающий параллельное создание правил.
- Входы участников сохраняются до ограниченной очереди Gateway. Переполнение обработки других событий не теряет AutoBan/AntiRaid job; повтор входа с тем же joined_at не дублирует его.

## Обновление установки

1. Остановите установленную службу и сделайте согласованную [резервную копию данных Open Bot](OPERATIONS.md), включая SQLite, uploads, ticket-files и очереди. Секреты и INTEGRATION_KEY храните отдельно от Git.
2. Получите `v1.3.0`, выполните `npm ci` и `npm run build`, затем запустите службу. Код на диске не обновляет уже работающие workers.
3. Миграции выполняются штатным Store; текущая последняя — `012-server-monitoring.sql`. Новые модули остаются opt-in. Рабочие настройки хранятся в панели, секреты и параметры развёртывания — в ENV.

## Приёмка и ограничения

Локальная приёмка:

- `npm run build`: успешно собраны TypeScript, React/Vite и backend.
- `npm run format:check` и `git diff --check`: успешно.
- `npm test`: 50 сценариев, **49 passed, 0 failed, 1 skipped**. Шесть новых регрессий проверяют Native AutoMod и сохранение входов при переполнении Gateway-очереди.
- `npm run docs:generate`: **23 страницы модулей, 40 статических slash-команд**, ручные дополнения сохранены.
- `python -m mkdocs build --strict`: успешно. В браузере открыто новое руководство: все семь изображений загрузились, ошибок консоли нет.
- Снимки панели проверены визуально; используются только FakeDiscord и демонстрационные данные.

Не считаются успешно пройденными проверками:

- Реальный Redis без `TEST_REDIS_URL`: интеграционный сценарий пропускается, локальная очередь проверяется отдельно.
- Docker Engine на машине владельца недоступен из-за виртуализации; контейнеры не собирались и не запускались.
- На рабочем Discord не запускались санкции, рассылки, восстановление guild и действия питания. Проверки используют FakeDiscord и локальные серверы протоколов.
- YouTube включает Shorts в общий поток; TikTok требует авторизованного creator. Все провайдеры требуют своих scopes/квот. Terraria требует TShock; Zomboid — настроенного A2S-порта.
- Восстановление Discord не возвращает исходные IDs, авторство/дату и чужие реакции. Частичные разделы отражаются в manifest; незавершённое восстановление защищает используемую копию от ротации.
- `npm audit` сообщает 3 moderate-предупреждения в цепочке `@fastify/static → glob → minimatch`. Автоматический совет npm понижает Fastify-плагин до несовместимой ветки и не применялся. Уязвимости не объявляются устранёнными.
- GitHub CI/Pages зависят от биллинга и плана аккаунта. Заблокированный до старта job не доказывает результат тестов; наличие source/workflow не означает опубликованную вики.
