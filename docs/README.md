## Справочники

Одна установка обслуживает один Discord-сервер. Open Bot публикует сообщения и правила, ведёт журнал административных действий. Состав выпуска и отдельно запланированные расширения указаны в [tasks.md](../tasks.md).

Документация открывается по `/docs/` на адресе установленной панели. Её Markdown-исходники доступны и прямо в репозитории. Иллюстрации панели сняты на изолированной демонстрационной установке без настоящих Discord-данных.
