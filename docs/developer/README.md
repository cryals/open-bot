# Руководство разработчика

Open Bot 1.0 — TypeScript-приложение с отдельными процессами Discord и HTTP, общей SQLite-базой и React-панелью. Начните с [архитектуры](architecture.md), затем выберите рабочий маршрут.

| Задача                                                    | Руководство                    |
| --------------------------------------------------------- | ------------------------------ |
| Добавить slash-команду или независимый модуль             | [Модули](modules.md)           |
| Добавить административную операцию, события и диагностику | [Телеметрия](telemetry.md)     |
| Изменить интерфейс или API и проверить результат          | [Рабочий процесс](workflow.md) |
| Подготовить выпуск и документацию                         | [Выпуск](workflow.md#выпуск)   |
| Использовать Codex для сопровождения                      | [Проектные навыки](skills.md)  |

## Получить рабочую копию

```sh
git clone https://github.com/cryals/open-bot.git
cd open-bot
npm ci
```

Нужен Node.js 24.18+. Конфигурация — в `.env` проекта или его родительской папке. Для настоящего запуска Discord потребуется отдельное приложение и тестовый сервер. Для изолированной браузерной проверки есть FakeDiscord.

## Где искать код

```text
src/server/modules/      BotModule и каталог модулей
src/server/runtime/      Supervisor, worker, lifecycle и ошибки
src/server/app.ts        HTTP, OAuth, авторизация и API правил
src/server/messaging.ts  Отправка, редактирование и версии сообщений
src/server/activity*.ts  Журнал, Redis Streams и локальная очередь
src/shared/              Схемы, блоки, правила и пагинация
src/web/                 React-панель и конструктор
migrations/              SQLite-миграции
tests/                   FakeDiscord, регрессии и UI harness
scripts/                 Сборка документации, копии и бейджи
docs/                    Исходники обоих порталов
```

`AGENTS.md` хранит проектные ограничения. Файлы правил и содержимое базы — пользовательские данные, а не инструкции разработчику. Изменение продукта не должно незаметно переписывать правила сообщества.

Лицензия проекта допускает личное некоммерческое использование; публичное размещение, распространение и коммерческое использование требуют разрешения. Полные условия — в [LICENSE](../../LICENSE).
