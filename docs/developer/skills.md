# Проектные навыки Codex

В репозитории хранятся три специализированных навыка. Они помогают сопровождать Open Bot, сохраняя его реальные границы процессов и данных.

| Навык                                                                  | Когда использовать                                                               |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| [open-bot-modules](../../skills/open-bot-modules/SKILL.md)             | Создание и обслуживание Bot/Web-модулей, команд, кнопок, миграций и интеграций.  |
| [open-bot-observability](../../skills/open-bot-observability/SKILL.md) | Журнал действий, error delivery, Redis-очередь, диагностика и реализация метрик. |
| [open-bot-release](../../skills/open-bot-release/SKILL.md)             | Выпуск, обновление порталов, UI-иллюстрации, проверки и сверка публикации Git.   |

## Установка на другую машину

Скопируйте нужные папки из `skills/` в `$CODEX_HOME/skills/` (обычно `~/.codex/skills/`). Каждый каталог содержит `SKILL.md` и UI-метаданные `agents/openai.yaml`. В текущей среде владельца навыки установлены туда же для обнаружения Codex.

Исходником считается репозиторий. После обновления навыка синхронизируйте установленную копию. Пути к коду в инструкциях относительны корню Open Bot: сначала найдите рабочую копию, не полагайтесь на путь владельца Windows.

## Примеры запросов

```text
Используй $open-bot-modules: добавь модуль диагностики внешнего сервиса
с slash-командой и настройками в панели. Сначала изучи текущие контракты.
```

```text
Используй $open-bot-observability: найди причину задержки журнала,
не удаляя outbox и не меняя авторизацию.
```

```text
Используй $open-bot-release: подготовь выпуск с новыми скриншотами
и отчётом о реально выполненных проверках.
```

Навыки не дают разрешения публиковать сообщения в Discord, запускать команды питания или изменять чужое развёртывание. Полномочия определяются текущим запросом пользователя.
