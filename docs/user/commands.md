# Slash-команды

Введите `/` в Discord и выберите команду Open Bot. Команды устанавливаются автоматически на сервер `GUILD_ID`.

| Команда                | Доступ        | Что делает                                                                                   |
| ---------------------- | ------------- | -------------------------------------------------------------------------------------------- |
| `/help [module]`       | Участники     | Справка по модулям; состав берётся из зарегистрированных команд.                             |
| `/ping`                | Участники     | Отвечает Pong, показывает время подтверждения Discord, Gateway ping и время работы процесса. |
| `/info`                | Участники     | Открывает личное меню опубликованных правил.                                                 |
| `/status`              | Администрация | Состояние процессов, модулей, память и число перезапусков.                                   |
| `/send-info [channel]` | Администрация | Публикует или обновляет информационное сообщение из последнего опубликованного снимка.       |

Ответы команд видны только вызвавшему их пользователю. `/send-info` дополнительно меняет публичное сообщение в целевом канале. Если указать другой канал, он становится новым каналом публикации; приложение пытается убрать прежнее сообщение.

## Кто считается администратором

На стороне приложения проверяется владелец сервера или настроенная административная роль. Если роль не задана, используется право Discord **Administrator**. Проверка актуальна на момент действия.

Для `/status` и `/send-info` также выставлены default permissions Administrator. Если ваша роль доступа не имеет этого права, владелец сервера может разрешить команды этой роли в настройках интеграции Discord. Это не заменяет проверку приложения.

## Если команда недоступна

Убедитесь, что бот установлен с scope `applications.commands`, вы на правильном сервере и интеграция разрешает команду вашей роли. Администратор может посмотреть состояние через `/status` и журнал запуска.

До первой публикации `/info` и `/send-info` сообщат, что опубликованных правил ещё нет. Сначала выполните [первую публикацию](rules.md) в панели.
