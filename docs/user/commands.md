# Slash-команды

Введите `/` в Discord и выберите команду Open Bot. Команды устанавливаются автоматически на сервер `GUILD_ID`.

| Команда                | Доступ        | Что делает                                                                                   |
| ---------------------- | ------------- | -------------------------------------------------------------------------------------------- |
| `/help [module]`       | Участники     | Справка по модулям; состав берётся из зарегистрированных команд.                             |
| `/ping`                | Участники     | Отвечает Pong, показывает время подтверждения Discord, Gateway ping и время работы процесса. |
| `/info`                | Участники     | Открывает личное меню опубликованных правил.                                                 |
| `/status`              | Администрация | Состояние процессов, модулей, память и число перезапусков.                                   |
| `/send-info [channel]` | Администрация | Публикует или обновляет информационное сообщение из последнего опубликованного снимка.       |

Ответы команд видны только вызвавшему их пользователю. `/send-info` дополнительно меняет публичное сообщение в целевом канале. Если указать другой канал, он становится новым каналом публикации; приложение пытается убрать прежнее сообщение.

## Команды новых модулей

| Команда                                                     | Доступ                                  | Назначение                                       |
| ----------------------------------------------------------- | --------------------------------------- | ------------------------------------------------ |
| `/ticket open`, `/ticket mine`                              | Участники                               | Создание и список своих активных обращений.      |
| `/ticket-panel channel`                                     | Полная роль Ticket/администратор        | Публикация настроенной панели.                   |
| `/ticket-manage action value`                               | Поддержка текущего тикета/администратор | Участники и категория через сохраняемое задание. |
| `/server-status [server]`                                   | Участники                               | Статус SS14.                                     |
| `/server-config list/add/remove/watch/unwatch`              | Администрация                           | Серверы и наблюдения.                            |
| `/watchdog list/add/remove/versions/action/restart-network` | Администрация                           | Конфигурация, версии и подтверждаемые операции.  |
| `/metrics`                                                  | Администрация                           | Состояние экспортёра без токена.                 |

Для `/ticket-panel` выставлены default permissions Manage Guild; разрешите команду нужной роли в настройках интеграции Discord. Это не заменяет проверку Ticket-роли на сервере приложения.

## Права администратора

На стороне приложения проверяется владелец сервера или настроенная административная роль. Если роль не задана, используется право Discord **Administrator**. Проверка актуальна на момент действия.

Для `/status` и `/send-info` также выставлены default permissions Administrator. Если ваша роль доступа не имеет этого права, владелец сервера может разрешить команды этой роли в настройках интеграции Discord. Это не заменяет проверку приложения.

### Модули сообщества

| Команды                                                                                                                                              | Полномочие                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `/warn`, `/note`, `/kick`, `/ban`, `/tempban`, `/softban`, `/unban`, `/timeout`, `/untimeout`, `/role-mute`, `/unmute`, `/purge`, `/lock`, `/unlock` | Управление модерацией; подтверждение и фактические Discord-права.                 |
| `/case`, `/warnings`                                                                                                                                 | Чтение модерации.                                                                 |
| `/automod`, `/autoban`, `/raid`, `/slowmode`                                                                                                         | Управление модерацией.                                                            |
| `/role-panel`, `/autoresponder`, `/custom`                                                                                                           | Настройка — управление ролями; `/custom run` проверяет доступ конкретной команды. |
| `/form open`                                                                                                                                         | Заявитель в пределах условий формы.                                               |
| `/form submissions`                                                                                                                                  | Чтение форм или соответствующая роль обработки.                                   |
| `/giveaway create/end/cancel/reroll`                                                                                                                 | Управление розыгрышами.                                                           |
| `/giveaway enter` и кнопки участия                                                                                                                   | Участники в пределах условий.                                                     |
| `/feed add/list/pause/remove`, `/starboard`                                                                                                          | Соответствующее полномочие модуля.                                                |
| `/backup create/list/status/restore`                                                                                                                 | Копии сервера; восстановление подтверждается отдельно.                            |

Ограничения описаны в [руководстве модулей](community.md). Источник `/help` — актуальный каталог, включая собственные slash-команды.

Убедитесь, что бот установлен с scope `applications.commands`, вы на правильном сервере и интеграция разрешает команду вашей роли. Администратор может посмотреть состояние через `/status` и журнал запуска.

До первой публикации `/info` и `/send-info` сообщат, что опубликованных правил ещё нет. Сначала выполните [первую публикацию](rules.md) в панели.
