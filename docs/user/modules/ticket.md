# Ticket

![Ticket — иллюстрация модуля](../../assets/modules/ticket.png)

Приватные обращения, служебные ветки и веб-архив.

**ID:** `ticket` · **Процесс:** Bot.

**Зависимости:** `core`.

## Команды

| Команда          | Назначение                  | Доступ                   |
| ---------------- | --------------------------- | ------------------------ |
| `/ticket open`   | Создать обращение           | Проверяется обработчиком |
| `/ticket mine`   | Мои активные обращения      | Проверяется обработчиком |
| `/ticket-panel`  | Опубликовать панель тикетов | Управление Ticket        |
| `/ticket-manage` | Управление текущим тикетом  | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
