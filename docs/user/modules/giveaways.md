# Розыгрыши

![Розыгрыши — иллюстрация модуля](../../assets/modules/giveaways.png)

Розыгрыши с условиями участия, сохраняемыми итогами и повторным выбором.

**ID:** `giveaways` · **Процесс:** Bot.

**Зависимости:** `community`.

**Права бота:** `SendMessages`.

## Команды

| Команда             | Назначение                                  | Доступ                   |
| ------------------- | ------------------------------------------- | ------------------------ |
| `/giveaway status`  | Состояние модуля                            | Проверяется обработчиком |
| `/giveaway enable`  | Включить модуль                             | Проверяется обработчиком |
| `/giveaway disable` | Выключить модуль                            | Проверяется обработчиком |
| `/giveaway create`  | Создать розыгрыш                            | Проверяется обработчиком |
| `/giveaway end`     | Розыгрыш: end                               | Проверяется обработчиком |
| `/giveaway cancel`  | Розыгрыш: cancel                            | Проверяется обработчиком |
| `/giveaway reroll`  | Розыгрыш: reroll                            | Проверяется обработчиком |
| `/giveaway enter`   | Принять участие с реферером (необязательно) | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
