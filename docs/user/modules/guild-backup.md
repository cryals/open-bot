# Копии Discord-сервера

Ежедневные снимки guild и поэтапное восстановление ролей, каналов и сообщений.

**ID:** `guild-backup` · **Процесс:** Bot.

**Зависимости:** `community`.

**Права бота:** `ReadMessageHistory`.

## Команды

| Команда           | Назначение                             | Доступ                   |
| ----------------- | -------------------------------------- | ------------------------ |
| `/backup status`  | Состояние модуля                       | Проверяется обработчиком |
| `/backup enable`  | Включить модуль                        | Проверяется обработчиком |
| `/backup disable` | Выключить модуль                       | Проверяется обработчиком |
| `/backup create`  | Создать снимок сервера                 | Проверяется обработчиком |
| `/backup list`    | Список копий                           | Проверяется обработчиком |
| `/backup restore` | Подготовить восстановление добавлением | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
