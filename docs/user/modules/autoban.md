# AutoBan

Правила новых входов по возрасту аккаунта, имени и инвайтам.

**ID:** `autoban` · **Процесс:** Bot.

**Зависимости:** `community`.

**События Gateway:** `members`.

**Права бота:** `BanMembers`.

## Команды

| Команда            | Назначение                 | Доступ                   |
| ------------------ | -------------------------- | ------------------------ |
| `/autoban status`  | Состояние модуля           | Проверяется обработчиком |
| `/autoban enable`  | Включить модуль            | Проверяется обработчиком |
| `/autoban disable` | Выключить модуль           | Проверяется обработчиком |
| `/autoban list`    | Список настроенных записей | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
