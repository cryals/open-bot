# Game Server Status

Состояние SS14-серверов и обновляемые сообщения.

**ID:** `game-server-status` · **Процесс:** Bot.

**Зависимости:** `core`.

## Команды

| Команда                  | Назначение                              | Доступ                   |
| ------------------------ | --------------------------------------- | ------------------------ |
| `/server-status`         | Статус SS14-сервера или список серверов | Проверяется обработчиком |
| `/server-config add`     | Добавить SS14-сервер                    | Администрация            |
| `/server-config remove`  | Удалить сервер                          | Администрация            |
| `/server-config watch`   | Обновляемый статус в канале             | Администрация            |
| `/server-config unwatch` | Убрать обновляемый статус               | Администрация            |
| `/server-config list`    | Серверы и наблюдения                    | Администрация            |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
