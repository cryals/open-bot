# Подписки

![Подписки — иллюстрация модуля](../../assets/modules/subscriptions.png)

Анонсы YouTube, Twitch, Kick, TikTok, Reddit и VK с очередью доставки.

**ID:** `subscriptions` · **Процесс:** Bot.

**Зависимости:** `community`.

**Права бота:** `SendMessages`, `EmbedLinks`.

## Команды

| Команда         | Назначение                 | Доступ                   |
| --------------- | -------------------------- | ------------------------ |
| `/feed status`  | Состояние модуля           | Проверяется обработчиком |
| `/feed enable`  | Включить модуль            | Проверяется обработчиком |
| `/feed disable` | Выключить модуль           | Проверяется обработчиком |
| `/feed list`    | Список настроенных записей | Проверяется обработчиком |
| `/feed add`     | Добавить подписку          | Проверяется обработчиком |
| `/feed pause`   | Подписка: pause            | Проверяется обработчиком |
| `/feed remove`  | Подписка: remove           | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
