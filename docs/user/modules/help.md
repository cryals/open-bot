# Help

![Help — иллюстрация модуля](../../assets/modules/help.png)

Справка из актуального реестра модулей и команд.

**ID:** `help` · **Процесс:** Bot.

**Зависимости:** `core`.

## Команды

| Команда | Назначение                         | Доступ                   |
| ------- | ---------------------------------- | ------------------------ |
| `/help` | Список доступных команд по модулям | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
