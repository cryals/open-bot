# Автоответы

![Автоответы — иллюстрация модуля](../../assets/modules/autoresponder.png)

Ответы и реакции на заданные фразы с приоритетами и cooldown.

**ID:** `autoresponder` · **Процесс:** Bot.

**Зависимости:** `community`.

**События Gateway:** `messages`, `messageContent`.

**Права бота:** `SendMessages`, `AddReactions`.

## Команды

| Команда                  | Назначение                 | Доступ                   |
| ------------------------ | -------------------------- | ------------------------ |
| `/autoresponder status`  | Состояние модуля           | Проверяется обработчиком |
| `/autoresponder enable`  | Включить модуль            | Проверяется обработчиком |
| `/autoresponder disable` | Выключить модуль           | Проверяется обработчиком |
| `/autoresponder list`    | Список настроенных записей | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
