# SS14 Watchdog

Подтверждаемые операции питания, обновления и отката SS14.

**ID:** `watchdog` · **Процесс:** Bot.

**Зависимости:** `core`.

## Команды

| Команда                     | Назначение                                     | Доступ        |
| --------------------------- | ---------------------------------------------- | ------------- |
| `/watchdog list`            | Настроенные Watchdog-серверы                   | Администрация |
| `/watchdog add`             | Добавить Watchdog-сервер; токен хранится в ENV | Администрация |
| `/watchdog remove`          | Убрать Watchdog-сервер                         | Администрация |
| `/watchdog versions`        | Доступные версии                               | Администрация |
| `/watchdog action`          | Подготовить действие с подтверждением          | Администрация |
| `/watchdog restart-network` | Подготовить перезапуск всех серверов           | Администрация |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
