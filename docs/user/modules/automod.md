# AutoMod

Фильтры сообщений, наблюдение, доказательства и автоматические санкции.

**ID:** `automod` · **Процесс:** Bot.

**Зависимости:** `community`.

**События Gateway:** `messages`, `messageContent`.

**Права бота:** `ViewChannel`, `ManageMessages`.

## Команды

| Команда            | Назначение                      | Доступ                   |
| ------------------ | ------------------------------- | ------------------------ |
| `/automod status`  | Состояние модуля                | Проверяется обработчиком |
| `/automod enable`  | Включить модуль                 | Проверяется обработчиком |
| `/automod disable` | Выключить модуль                | Проверяется обработчиком |
| `/automod sync`    | Синхронизировать Native AutoMod | Проверяется обработчиком |
| `/automod rule`    | Показать правило                | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
