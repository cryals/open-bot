# Свои команды

Пользовательские slash-команды с параметрами, шаблонами и разрешёнными действиями.

**ID:** `custom-commands` · **Процесс:** Bot.

**Зависимости:** `community`.

**Права бота:** `SendMessages`.

## Команды

| Команда           | Назначение                         | Доступ                   |
| ----------------- | ---------------------------------- | ------------------------ |
| `/custom status`  | Состояние модуля                   | Проверяется обработчиком |
| `/custom enable`  | Включить модуль                    | Проверяется обработчиком |
| `/custom disable` | Выключить модуль                   | Проверяется обработчиком |
| `/custom run`     | Выполнить пользовательскую команду | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.

Пользовательские slash-команды зависят от сохранённой конфигурации и появляются после регистрации через панель. В статический каталог они не включены.
