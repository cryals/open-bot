# Moderation

Дела, предупреждения и подтверждаемые наказания.

**ID:** `moderation` · **Процесс:** Bot.

**Зависимости:** `core`.

**Права бота:** `ModerateMembers`.

## Команды

| Команда      | Назначение               | Доступ                |
| ------------ | ------------------------ | --------------------- |
| `/warn`      | Предупреждение           | Модерация и наказания |
| `/note`      | Заметка                  | Модерация и наказания |
| `/kick`      | Исключение               | Модерация и наказания |
| `/ban`       | Блокировка               | Модерация и наказания |
| `/tempban`   | Временная блокировка     | Модерация и наказания |
| `/softban`   | Softban                  | Модерация и наказания |
| `/unban`     | Снятие блокировки        | Модерация и наказания |
| `/timeout`   | Тайм-аут                 | Модерация и наказания |
| `/untimeout` | Снятие тайм-аута         | Модерация и наказания |
| `/role-mute` | Ролевой мут              | Модерация и наказания |
| `/unmute`    | Снятие мута              | Модерация и наказания |
| `/purge`     | Очистка сообщений        | Модерация и наказания |
| `/lock`      | Закрытие канала          | Модерация и наказания |
| `/unlock`    | Открытие канала          | Модерация и наказания |
| `/warnings`  | Предупреждения участника | Чтение дел модерации  |
| `/case`      | Дело модерации           | Чтение дел модерации  |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
