# AntiRaid

Защитный режим при массовых входах, карантин и временные ограничения каналов.

**ID:** `anti-raid` · **Процесс:** Bot.

**Зависимости:** `community`.

**События Gateway:** `members`.

**Права бота:** `ModerateMembers`.

## Команды

| Команда         | Назначение               | Доступ                   |
| --------------- | ------------------------ | ------------------------ |
| `/raid status`  | Состояние модуля         | Проверяется обработчиком |
| `/raid enable`  | Включить модуль          | Проверяется обработчиком |
| `/raid disable` | Выключить модуль         | Проверяется обработчиком |
| `/raid start`   | Включить защитный режим  | Проверяется обработчиком |
| `/raid stop`    | Выключить защитный режим | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
