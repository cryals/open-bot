# Core

![Core — иллюстрация модуля](../../assets/modules/core.png)

Подключение бота, жизненный цикл модулей и диагностика.

**ID:** `core` · **Процесс:** Bot.

## Команды

| Команда   | Назначение                    | Доступ                   |
| --------- | ----------------------------- | ------------------------ |
| `/ping`   | Проверить задержку бота       | Проверяется обработчиком |
| `/status` | Состояние модулей и процессов | Администрация            |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
