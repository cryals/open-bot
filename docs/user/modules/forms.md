# Формы и апелляции

![Формы и апелляции — иллюстрация модуля](../../assets/modules/forms.png)

Приём заявок в Discord и через веб, обработка решений и апелляций.

**ID:** `forms` · **Процесс:** Bot.

**Зависимости:** `community`.

**Права бота:** `SendMessages`.

## Команды

| Команда             | Назначение                   | Доступ                   |
| ------------------- | ---------------------------- | ------------------------ |
| `/form status`      | Состояние модуля             | Проверяется обработчиком |
| `/form enable`      | Включить модуль              | Проверяется обработчиком |
| `/form disable`     | Выключить модуль             | Проверяется обработчиком |
| `/form open`        | Заполнить форму              | Проверяется обработчиком |
| `/form submissions` | Заявки, доступные сотруднику | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
