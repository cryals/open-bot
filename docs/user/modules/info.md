# Info

Информация проекта и персональные страницы правил.

**ID:** `info` · **Процесс:** Bot.

**Зависимости:** `core`.

## Команды

| Команда      | Назначение                                               | Доступ                   |
| ------------ | -------------------------------------------------------- | ------------------------ |
| `/info`      | Открыть правила Discord и игры                           | Проверяется обработчиком |
| `/send-info` | Отправить или обновить опубликованную информацию проекта | Администрация            |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
