# Панели ролей

Безопасная выдача ролей через кнопки, меню и реакции.

**ID:** `role-menus` · **Процесс:** Bot.

**Зависимости:** `community`.

**События Gateway:** `messages`, `messageContent`, `reactions`.

**Права бота:** `ManageRoles`, `SendMessages`.

## Команды

| Команда                 | Назначение                      | Доступ                   |
| ----------------------- | ------------------------------- | ------------------------ |
| `/role-panel status`    | Состояние модуля                | Проверяется обработчиком |
| `/role-panel enable`    | Включить модуль                 | Проверяется обработчиком |
| `/role-panel disable`   | Выключить модуль                | Проверяется обработчиком |
| `/role-panel publish`   | Опубликовать панель ролей       | Проверяется обработчиком |
| `/role-panel unpublish` | Отключить опубликованную панель | Проверяется обработчиком |

Доступ проверяется по актуальным ролям и правам Discord. У отдельных подкоманд могут быть дополнительные ограничения; справочник не выдаёт полномочий.
