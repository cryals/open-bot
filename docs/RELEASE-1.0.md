# Open Bot 1.0 — релиз

Дата подготовки: **30 октября 2026 года**.

## Состав

Core, Web, Help, Info, Ticket, Metrics, Game Server Status и SS14 Watchdog. Правила и сообщения используют Components V2. Включены веб-панель, OAuth, опубликованные версии, конструктор, административный журнал, Redis batching с локальной очередью и обработка сбоев процессов.

Ticket включает категории/формы, приватные каналы, служебные ветки, веб-транскрипты и 180-дневную очистку. Status переносит поведение актуального wizard-cogs. Watchdog сохраняет подтверждения и неизвестные результаты без автоматического повтора POST. Metrics работает в отдельном процессе с bearer token и готовым Grafana dashboard.

Документация перенесена из самописного HTML в отдельную вики MkDocs Material. Приложение больше не собирает и не обслуживает `/docs/`. Поиск и пользовательский/разработческий разделы формируются из Markdown; CI/CD документации отделён от runtime.

## Доказательства

Результаты текущего прогона фиксируются после завершения локальных проверок. Ограничения, которые не могут считаться успешными проверками:

- Реальный Redis integration требует `TEST_REDIS_URL`; без него тест пропускается.
- Docker Engine недоступен на Windows-машине владельца из-за виртуализации. Контейнеры не собирались и не запускались; Docker/WSL/Hyper-V не ремонтировались.
- Живые Discord-публикации и реальные команды питания не используются для разработки. Изолированные сценарии выполняются на FakeDiscord и локальном HTTP mock.
- GitHub Actions и Pages зависят от разрешений/плана/биллинга аккаунта. Наличие workflow не означает успешный облачный запуск.

## Обновление

Перед миграцией `007-modules.sql` остановите установленную службу и сделайте согласованную копию SQLite, uploads, ticket-files и очередей. Обновите исходники и зависимости, соберите приложение и запустите службу. Новые Ticket/Metrics по умолчанию выключены до настройки окружения и прав Discord.

## Результаты локальной приёмки

- `npm run check`: **35 passed, 0 failed, 1 skipped** (Redis без `TEST_REDIS_URL`).
- `npm run build`: TypeScript, React/Vite и backend собраны успешно. Вики в эту сборку не входит.
- `python -m mkdocs build --strict`: успешная отдельная сборка. Кириллические anchors и поиск сохранены; внутренние specs/review не опубликованы.
- `npm audit --omit=dev`: 0 известных уязвимостей на момент проверки.
- Три проектных навыка прошли `quick_validate.py`.
- Playwright/FakeDiscord: административный UI, SS14 status, подтверждение Watchdog на локальном mock, роли Ticket viewer/manager и запрет автору staff scope. Поиск MkDocs на запрос «тикеты» возвращает руководство.
- Ревью выявило и устранило обход unknown-блокировки старым подтверждением, дубли физических Watchdog targets, удаление активной категории при выключении Ticket, переполнение анкеты и потерю истории пустой правки. Для них добавлены регрессии.
- GitHub API вернул **HTTP 422: текущий план не поддерживает Pages для этого private repository**. Workflow и wiki source доступны в Git; работающая публичная Pages-публикация не заявляется. Visibility и billing не менялись.
