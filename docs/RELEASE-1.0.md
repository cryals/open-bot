# Open Bot 1.0 — релиз

Дата подготовки: **30 октября 2026 года**.

## Состав

Выпуск включает правила и информационное сообщение Components V2, визуальный конструктор сообщений, Discord OAuth, опубликованные версии, административный журнал, Redis batching с локальной очередью и модульный runtime Core / Web / Help / Info.

Добавлены два портала по `/docs/`: [пользователю](user/README.md) и [разработчику](developer/README.md). Документация содержит шесть исходных скриншотов панели и отдельную аннотированную иллюстрацию редактора. Markdown остаётся исходным форматом; HTML собирается вместе с приложением без новой production-зависимости.

Статус продукта изменён на **Релиз** в README, бейдже и панели. Индикатор версии черновика сохранён, поскольку он относится к содержимому.

## Ограничения проверки

- `TEST_REDIS_URL` не настроен. Реальный Redis integration пропущен; FakeDiscord/outbox-сценарии выполнены.
- Docker Engine недоступен на Windows-машине владельца из-за виртуализации. Сборка и запуск контейнеров не выполнялись. Docker/WSL/Hyper-V не запускались и не ремонтировались.
- GitHub Actions для предыдущего коммита был заблокирован до запуска job из-за биллинга/лимита аккаунта. Такой результат не считается результатом тестов; локальная проверка описана отдельно.
- На живом Discord-сервере не выполнялись тестовые публикации. Скриншоты содержат демонстрационные ID и аккаунт.

## Расширения вне этого выпуска

Ticket и Metrics существуют пока в виде согласованного дизайна. Game Server Status и SS14 Watchdog Power Actions запрошены отдельно, но ещё не реализованы. Они не входят в текущий каталог модулей; `/metrics`, транскриптов тикетов и команд питания в 1.0 нет. Подробности остаются в [состоянии проекта](../tasks.md).

## Обновление

Остановите установленную службу и сделайте согласованную резервную копию перед обновлением. Обновите исходники и зависимости, выполните `npm run build`, затем запустите службу. Новых миграций базы этот выпуск документации не добавляет. Руководства доступны по `/docs/` на том же хосте, что панель.
